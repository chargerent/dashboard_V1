# Dashboard 1.112 and hosted kiosk app 0.9.37 (build 88)

Rental complete now reserves the receipt QR and caption space before the receipt is available. Pending and ready captions share a fixed measured area, so receipt arrival or QR regeneration does not change the return message position. The preview aligns before painting and retains the alignment across equivalent profile refreshes; the native view preserves its measured return offset across receipt updates with the same layout inputs.

The last return-instruction line remains aligned with the receipt caption. Return complete retains its receipt updates, and touch checkout keeps its existing Done flow.

Regression evidence: the stability test reproduces a 132-pixel shift with the previous renderer. The corrected renderer stays within 1 pixel through initial receipt delivery, changing receipt links, and repeated receipt refreshes in both orientations, English/French/Spanish, 15 and 28 percent panel heights, and multiline captions. Validation also covers receipt delivery/dismissal, outage cards, return icons and rounded QR styling, with 15 browser tests, 21 focused dashboard Node tests, 113 media web tests, hosted Android tests, release lint, and production builds.
